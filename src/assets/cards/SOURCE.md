## 重要说明

这套立绘是**西幻动漫风的占位素材**，不是三国原画，也不完全符合人物造型（例如关羽没有长髯与青龙偃月刀）。选它是因为：

1. 许可干净，CC0，可商用、可修改、可再分发；
2. 同一画师、同一比例、透明背景，六张卡面能保持统一；
3. 动漫赛璐璐画风明确，不是 Q 版或卡通。

正式发布前建议替换为项目定制立绘。卡面背景、武器剪影、印章、纹理均由本项目手写 CSS / SVG 生成，不属于素材包。
