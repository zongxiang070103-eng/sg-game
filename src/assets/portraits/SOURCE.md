# 水墨立绘来源

六十张整幅水墨场景立绘来自项目维护者提供的 **《战棋 · 水墨武将立绘资源包 v1.0》**（2026-11-01）。

- 原图：`art/<武将id>.png`，1024×1536，PNG，与 `data/generals.json` 的 60 个 id 一一对应。
- 处理：裁掉底部 72px（去除右下角生成平台水印），等比缩放到 640×915，转 WebP quality 80。
- 本目录只保留优化后的 `.webp`；原始 172MB PNG 不进入仓库。
- 立绘为 AI 生成，资源包 README 注明“仅供资源替换/展示使用”。公开发布前请再次确认生成平台条款。
- 界面中的卡框、压暗、印章、名字排版与状态标签仍由本项目 CSS 绘制，不属于素材包。
