# 将星谱 · 设计说明

## 方向

**一句话**：把 3v3 明牌战棋做成一沓会发光的武将海报，战场就是卡阵，操作就是翻牌、点目标、亮战法。

**设计读法**：用户先看到的是「武将在夜里列阵」，不是「后台数据面板」。所以主视觉必须是人物、卡框、竖排姓名与势力色；数值和按钮退到第二层。首页是一张大海报 + 六张将卡，战场是上下两排卡，所有浮层都继续使用同一套卡语言。

**明确不做**：

- Q 版、三头身、卡通描边；
- 红金渐变 + 圆角卡片的通用三国手游模板；
- 直接使用《三国杀》、光荣或其他商业三国游戏的卡框、立绘、图标、字体；
- 满屏飘字、无意义的粒子与「过渡动画大礼包」。

## 设计系统

### 色彩

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--night` | `#080b14` | 最深底色 |
| `--night-2` | `#0e1424` | 面板 / 卡底 |
| `--night-3` | `#141c30` | 抬升层 |
| `--paper` | `#f2e7d3` | 主文字、卡名 |
| `--paper-dim` | `#c9bda8` | 次级文字 |
| `--ink` | `#05070c` | 页面底色、暗角 |
| `--gold` | `#e0b264` | 边框、稀有度、当前行动 |
| `--gold-2` | `#f6dca6` | 高光、焦点环 |
| `--red` | `#e2492f` | 伤害、目标、朱印、主 CTA |
| `--red-2` | `#ff7a5c` | 伤害高光 |
| `--jade` | `#57c29a` | 蜀方气血 |
| `--blue` | `#6f9de8` | 魏方气血、护盾 |

规则：

- 红只给「伤害 / 目标 / 印章 / 出征」；生命条改走势力色（蜀绿、魏蓝），低于 30% 才转红。
- 金用于「当前行动 / 可交互边框 / 稀有度」，不是大面积背景。
- 每名武将另有 `--accent` 与 `--accent-2`，用于卡面渐变、环形光与气血条；六人仍统一在青绿 / 靛蓝两族里。

### 字体

- 展示：`Songti SC / STSong / SimSun / Noto Serif SC`，竖排姓名、印章、结算大字。
- 正文：`PingFang SC / Microsoft YaHei / Noto Sans SC`。
- 数字：`Bahnschrift / DIN Alternate / Consolas`，生命、攻防速、回合、评价。

不使用外部字体文件，避免 `file://` 与离线环境出现字体请求失败。

### 卡牌解剖

```
.card
  .card-frame         切角金线 + 内框
    .card-art         势力渐变 / 水墨场景 / 旋转光环 / 武器剪影 / 水印字
      .card-portrait  全身立绘
      .card-scrim     底部暗角
      .card-shine     指针扫光
      .card-foil      斜向箔纹
    .card-top         势力徽记 + 五星
    .card-shield      战斗中的「盾 N」
    .card-name        竖排姓名 + 称号
    .card-seal        朱印
    .card-foot        生命条 + 攻 / 防 / 速
```

- 宽高比 `3 / 4.12`，容器查询以卡宽为基准缩放文字，不依赖页面断点。
- 卡宽小于 170px 时隐藏称号与攻防速；小于 118px 时只留姓名、势力与生命条。
- 卡框使用 `clip-path` 切掉右上、左下两角，内层再用 1px 金线复刻切角，形成「双层卡框」。
- 倾斜使用独立的 `rotate` / `translate` / `scale` 属性，避免与 `transform` 动画互相覆盖。

### 布局

- 首页三栏：竖排品牌 / 大海报 / 点将网格。桌面 `150px minmax(280px,390px) 1fr`，1024 降到 `80px minmax(240px,310px) 1fr`，760 以下改为单栏。
- 战场四行：敌阵 / 中轴 / 我阵 / 军令。中轴放回合、出手顺序与提示。
- 结算是一张带切角的「战报海报」，仍使用金线、朱印与竖排基因里的大字。

## 交互模型

1. **卡片即按钮**：首页将卡是主将选择器；战场敌将卡是目标选择器；我方卡与已倒下卡是详报入口。
2. **一次行动只做一件事**：点目标 → 点战法 / 普攻 / 防御。动作后进入 `busy`，军令栏禁用，避免连点。
3. **状态直接画在卡上**：金色「行动」、红色「目标」角标、`盾 N`、灰色「败」印。数值变化同时飘字。
4. **战报是第二条叙事线**：抽屉按时间倒序，颜色区分技能 / 伤害 / 治疗；屏幕阅读器通过隐藏的 `aria-live` 区域收到同一句话。
5. **浮层一层一层来**：详报、战报、结算同一时间只开一个；`Esc` 关闭；焦点进入浮层后被约束，关闭时回到触发元素。

## 动效

- 入场：页面淡入；卡牌 `card-in` 轻微上浮 + 错峰；换主将时大海报 `feature-swap` 轻换。
- 常驻：卡面圆环 90s 慢转；大海报与选中卡周期扫光；舞台云层漂移、余烬上浮、光晕呼吸。
- 交互：鼠标设备才有 3D 倾斜与扫光；触屏不做。
- 战斗：行动卡前冲；施法时金线从出手者扫向目标；命中出现冲击环与火星；倒下时卡面过曝、灰化；轮到己方时中轴扫光、行动卡金环；伤害、治疗、护盾仍用浮字。
- 结算：战报海报 `poster-in`，朱印 `stamp-in` 与外扩环，背后放射纹缓慢旋转。
- `prefers-reduced-motion` 下所有 CSS 动画缩到 0.001ms，JS 的回合等待从 900ms 降到 120ms；光束、火星、扫光不会创建。

## 声音

- 全部由 Web Audio 实时合成，没有音频文件，避免 `file://` 下的加载与许可问题。
- 音效走短包络：三角波做界面轻点与拨弦，带通噪声做刀风，低频正弦做命中与倒下，高金属音做护盾，长衰减正弦做胜负。
- 环境音乐用 73.42Hz / 110Hz 的低音持续音加低通滤波，再随机点缀五声音阶拨弦；默认关闭，音量控制得很低。
- 音效与环境音乐是两条独立总线，分别由顶部两个按钮控制；状态存 `localStorage`。浏览器要求首次点击或按键后才允许建立 AudioContext。
- 音频开关使用 `aria-pressed`，关闭时图标加斜线，不只靠颜色。
- 减少动态效果不影响声音：视觉可以停，功能不被一并关掉。

## 将星图鉴

### 概念

图鉴不是战斗界面的延伸，而是一册摊在暗台上的**纸本档案**：深色舞台把注意力让给纸页，纸页上是墨线、朱印、金线、竖排姓名。与首页「夜战卡阵」共用金 / 朱 / 纸三色，但把大面积夜色换成大面积纸色，形成「战阵」与「册页」两种阅读节奏。

- 桌面：上方是题签式标签（人物志 / 战役志 / 成就录），下方是六列海报墙；筛选与搜索放在纸页内，不漂浮在暗台上。
- 详情：左右对开的册页。左页是图版与题签，右页是名、字、称号、定位、五项属性条、两个战法、势力 / 相关战役、标签与前后翻页。
- 窄屏：海报墙降为二列，详情改为单页竖排；图版在上，文字在下，关闭按钮固定在右上。

### 图版系统

- **历史图版**：57 位人物全部使用公有领域历史图像——43 张 WDL11391 清大魁堂刊回目插图，7 张旧有清刻 / 颐和园长廊彩绘（张飞、马超共用一张），以及 6 张补缺图版：清刻「孔明造木牛流马」、吴友如《古今百美图》「二乔」「文姬」、清刻刘表绣像、歌川国芳 1854 年浮世绘《孔明六擒孟获》。卡片上做 3:4 竖幅裁切，让画面成为「海报」；详情页以 `object-fit: contain` 完整展示原刻边框与题记，像装裱在纸页上的图版。
- **补缺原则**：没有对应回目插图时，优先选「画面能读出一个具体事件」的古版画，而不是随便找一张人物像。黄月英用「木牛流马」图，刘表用题「安坐镇荆州」的绣像，祝融夫人用浮世绘中的南征出战；图注说明画面所绘，也说明人物是否真的出现在画中。
- **史料分层（仅战役）**：战役页仍标 **史实 / 演义 / 传说**，`recordNote` 说明与正史的差异；人物页不再承担史料辨析，只记游戏面板。
- **事件优先**：选图先问「这张画能不能看出是哪一回」，再问构图。曹仁用「水淹七军」的守城视角、张角用「斩黄巾」、汉献帝用「董国舅内阁受诏」，都是事件优先于人物露脸。

### 面板系统

- **字段**：生命 / 攻击 / 防御 / 智力 / 速度五项，各按当前名册上限归一为条长（132 / 34 / 25 / 35 / 19）；数值仍以数字给出，条只负责比较。
- **战法**：每人两个，列出名称、冷却回合、作用目标与效果说明；目标词表沿用演武场（单体敌人、生命最低的敌人、攻击最高的敌人、全体敌人、自身、生命最低的友军、全体友军）。
- **数据分层**：图鉴收录的 17 名演武场武将取 `data/generals.json` 与 `data/skills.json` 原值；其余 40 人在 `codex-roster.js` 中按同一区间与格式补齐。两套数据不混写，便于以后把补齐角色并入正式数据。
- **版式**：属性条用势力色，战法卡用纸色底与细边框；右页在 1440 高度内不滚动，窄屏随册页自然下延。

### 交互

- 路由：`#codex`、`#codex/battles`、`#codex/achievements`、`#codex/char/<id>`、`#codex/battle/<id>`。刷新后保留当前页。
- 人物按势力分组；势力筛选，姓名 / 字 / 称号 / 定位 / 标签 / 战法搜索，结果数通过 `aria-live` 播报。
- 详情内左右方向键翻页，`Esc` 关闭，关闭后焦点回到原卡片；前后翻页按当前筛选后的顺序。
- 已阅人物、已读战役、成就进度、胜场 / 评价 / 完胜 / 速战写入 `localStorage`（`jiangxing.codex.v1`）；完成战斗会回写成就。
- 图鉴内的动效克制：纸页不入场旋转，只有卡片悬停轻抬、详情翻页淡入、朱印落章；`prefers-reduced-motion` 下关闭。

### 响应式与可访问性

| 宽度 | 海报墙 | 详情 |
| --- | --- | --- |
| ≥1280px | 6 列 | 左右对开 |
| 1080px | 5 列 | 左右对开 |
| 900px | 4 列 | 左右对开，页边收窄 |
| 760px | 3 列 | 单页竖排 |
| 420px | 2 列 | 单页竖排，图版缩短 |

- 卡片是 `<button>`，有可读的 `aria-label`（姓名、字、事件）；详情是模态对话框，Tab 约束在层内。
- 图版 `alt` 为空，事件信息由相邻文字承担，避免重复朗读。
- 势力色不只靠颜色：同时有「魏 / 蜀 / 吴 / 群」文字徽记。
- 筛选按钮使用 `aria-pressed`，结果计数用 `aria-live="polite"`。

## 响应式

| 断点 | 变化 |
| --- | --- |
| `1100px` | 首页品牌缩窄，海报列收窄，将卡间距变小 |
| `900px` | 首页点将网格改为两列，战场卡阵略缩 |
| `760px` | 首页单栏、将卡横滑；战场保留三对三；详报改上下布局；军令栏五列；首页顶部保留音效 / 环境音乐开关，隐藏设置占位 |
| `480px` | 隐藏第三个资源、缩小结算内边距、战场卡进一步缩小 |

手机端首页采用「大海报 + 横滑将卡」，是为了保留海报尺度，而不是把六张卡压成缩略图网格。

## 可访问性

- 所有可点卡牌是 `role="button"` + `tabindex="0"`，`Enter` / `Space` 可触发；详报内的卡改为 `role="img"`，不重复进入 Tab 序列。
- 生命条 `role="progressbar"`，带 `aria-valuenow/max` 与姓名。
- 详报、战报、结算都是模态层，Tab 循环约束在层内；`Esc` 关闭；关闭后焦点回到触发按钮。
- 战斗事件写入隐藏 `aria-live` 区域；战报列表本身也有 `aria-live="polite"`。
- 焦点环统一为 2px 金色外描边；触控目标不小于 44px。
- 音频开关是可切换按钮，带 `aria-pressed` 与「开 / 关」文案；关闭状态有斜线图形，不只靠颜色。
- 移动端仍保留音效与环境音乐两个 44px 触控按钮。
- 低动态偏好同时影响 CSS 与 JS 节奏，但不影响音频开关。

## 取舍与已知问题

- **立绘是占位**：六张 CC0 素材是西幻动漫风，不是三国人物；关羽没有长髯，张辽穿的是圣殿骑士甲。正式发布前必须替换。卡面场景、武器剪影与卡框是本项目手写的，可以保留。
- **战斗是 UI 演示**：只实现伤害、护盾、吸血、冷却、条件倍率与简单 AI；没有控制、增减益、后援、30 回合判定与确定性种子。真实战斗以根目录 README 为准。
- **手机详报需要滚动**：内容高度超过一屏时，关闭按钮固定在右上角，正文可滚。
- **立绘色温不完全统一**：靠势力渐变、暗角、金色卡框把人像收进同一套视觉；后续换定制立绘后可进一步统一。
- **40 人面板是补齐数据**：图鉴中 17 名演武场武将取 `data/` 原值；其余 40 人的属性与战法按同一区间补齐，未经正式平衡验证。
- **声音是合成的概念音**：不是录制素材，没有音量滑杆与多轨 BGM；浏览器要求首次交互后才允许播放。顶部两个按钮现在真实可用。
- **没有后端 / 云存档**：战斗本身刷新即重置；音频开关与图鉴进度写入浏览器 `localStorage`，换浏览器或清缓存会丢失。
- **图鉴图版不是定制原画**：57 张海报来自公有领域版画、绣像与彩绘，刻工、纸色、尺寸与清晰度不齐（刘表绣像原图仅 359×479，祝融夫人原图为浮世绘，与清刻线描风格不同）。已尽量统一色调与纸感，并在来源中逐条注明。正式发布若要求统一画风，应替换为项目定制海报。
- **同图共用**：法正与黄忠共用定军山图版，大乔与小乔共用《古今百美图》「二乔」，卡片裁切不同；详情页共用整幅，图注已说明。
- **补缺图不完全「人物露脸」**：黄月英的图版画的是孔明造木牛流马，她本人不在画中；刘表、祝融夫人用人物绣像 / 浮世绘，事件信息由题记与图注补足。
