> 当前进度、阻塞点与下一步命令见 [`HANDOFF.md`](HANDOFF.md)。**出图渠道已选火山方舟 Seedream 5 Pro，账户欠费暂停。**

目标：把图鉴里的 57 张古版画换成「事件立绘」——二次元赛璐璐画风，每张画的是该角色在某个具体历史事件中的样子（参照神赵云式的立绘思路）。

## 现状

- `_art-review/` 有三张试做图（关羽、赵云、诸葛亮），用 FLUX.1-schnell 生成，用于确认画风与构图。
- `gen-portraits.py` 里有全部 57 位角色的提示词（人物外形 + 事件场景 + 固定画风），以及一个调用公开 FLUX 演示空间的脚本。
- 公开演示空间的免费 GPU 配额很小（约 1 分钟/天，匿名），试做 4 张后被限流，今天无法生成全部 57 张。需要换一个出图渠道。

## 出图渠道

已选定：**火山方舟 Doubao Seedream 5 Pro**（`_art/gen-ark.py`，模型 `doubao-seedream-5-0-pro-260628`，864×1152，`watermark: false`）。key 从 `ARK_API_KEY` 环境变量读取，不写入仓库。

备选：`gen-portraits.py` 里的 Hugging Face FLUX 演示空间（免费额度约 1 分钟/天，仅够试做几张）；或把 `--list` 的提示词贴到即梦/豆包/Midjourney 手动出图，按 `<id>.webp` 放回 `_art/out/`。

## 出图后的接入

1. 逐张复核（武器、服饰、构图、有无乱码文字），不合格的用同 id 重生成。
2. 统一转 `assets/codex/portrait/<id>.webp`（3:4，WebP q90）。
3. 把 `codex.js` 的图版映射改成 `portrait/<id>.webp`，卡片与册页都读它。
4. 图注从「清刻 / 公有领域」改为「角色立绘 · AI 生成」，并去掉正文里「图版为清刻……」的句子。

## 画风约束

- 二次元赛璐璐：平涂、干净线稿、鲜明配色；不要写实厚涂，不要 Q 版。
- 全身体、动态构图、背景交代事件现场。
- 历史向：汉末三国甲胄、幞巾、曲裾/直裾、环首刀、戟、矛、羽扇；不出现现代物件、奇幻盔甲。
- 不要在提示词里要求画中文字（模型会写出乱码），姓名由界面叠加。
